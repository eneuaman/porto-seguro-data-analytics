# Porto Seguro's Safe Driver Prediction

This project was developed as part of the "Advanced Data Analytics" module during my Master's degree in Data Analytics (M.Sc.) at Justus-Liebig-University Giessen.

## Project Overview
The goal of this project is to build a predictive machine learning model that predicts the probability that a driver will initiate an auto insurance claim in the next year. The dataset is based on the popular Kaggle competition "Porto Seguro".

## Key Skills & Methods applied:
- Extensive Exploratory Data Analysis (EDA) on anonymized features.
- Handling highly imbalanced data (Imbalanced Classes).
- Feature Engineering and Data Preprocessing.
- Implementation and evaluation of Machine Learning models (Scikit-learn, PyTorch/TensorFlow) to optimize predictive performance.
